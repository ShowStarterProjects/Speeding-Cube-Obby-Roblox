# Speeding-Cube-Obby-Roblox

"An angry cube is chasing you, run!!!"


## Description

A fun Roblox game where a speeding cube chases you as you make your way through the obstacle course to get to safety.
There are different themes and styles for every level to make you less stressed about the giant cube.
